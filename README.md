# DISCLOSED ($DSCL)

Coins on Robinhood Chain whose stock rewards copy a real, public filing — a fund's 13F,
an insider's Form 4, a lawmaker's disclosure. Trading fees route into the coin's vault,
the vault buys exactly what the filing says, holders claim the stock tokens, and the basket
rebalances when the next document lands.

Single self-contained `index.html`, no build step.
Settings (contract, X, buy link, WalletConnect project id) live in the first `<script>` block.
